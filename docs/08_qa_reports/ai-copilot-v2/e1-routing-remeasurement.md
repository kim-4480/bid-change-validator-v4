# AI Copilot E1 — 동일 자유입력 라우팅 재측정

- E0: **1/100 = 1.0%**
- 현재 E1 구현분: **41/100 = 41.0%**
- 변화: **+40.0%p**

> 이 값은 프론트 E1의 제한적 alias를 적용한 뒤 기존 Backend `route_intent()`로 보내는 **정적 코드 경로 재측정**이다. 실제 API/DB/브라우저 E2E 결과나 전체 챗봇 정확도가 아니다.

| 묶음 | E0 | E1 현재 구현분 |
|---|---:|---:|
| 문서 QA | 1/60 (1.7%) | 1/60 (1.7%) |
| 판정 설명 | 0/32 (0.0%) | 32/32 (100.0%) |
| 변경 비교 | 0/8 (0.0%) | 8/8 (100.0%) |

## 해석
- 판정 설명 32개는 `우리/저희/당사 + 참가할 수/넣어도 돼`의 고신뢰 alias로 복구된다.
- 변경 비교 8개는 `무엇이 바뀌었는지/바뀐 내용` alias로 복구된다.
- 문서 QA는 **1/60**으로 사실상 개선되지 않았다. 문서 의미 이해를 규칙 alias로 넓히지 않고 E2/E3로 남긴 결과다.
- 따라서 E1의 상승분을 LLM 성능 향상으로 표현하지 않는다.
